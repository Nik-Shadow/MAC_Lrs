# Многоагентная система: учебный проект для 4 лабораторных

**Предмет:** Теория многоагентных систем.  
**Тема:** распределение вычислительных задач между автономными агентами, переговоры за общий GPU и оценка отказоустойчивости.

## Состав

- `mas_sim.py` — вся работающая логика симулятора: типы агентов, взаимодействие, распределение, торг, атаки и защита;
- `tests/test_simulation.py` — 7 автоматических тестов;
- `reports/lab1.docx` … `reports/lab4.docx` — отчеты;
- `figures/*.png` — диаграммы и графики из экспериментов;
- `diagrams/*.mmd`, `diagrams/*.dot` — редактируемые исходники диаграмм;
- `results/lab*_trials.csv` — все результаты отдельных испытаний;
- `results/lab*_summary.csv` и `results/summary.json` — средние значения по 20 испытаниям;
- `results/message_traces.json` — примеры журналов сообщений, включая все события в защищенных сценариях отказов.

## Как запускать

В терминале из папки проекта:

```bash
python mas_sim.py --lab all --trials 20 --trace
```

Команда генерирует сводные таблицы для работ 2, 3, 4, сохраняет CSV/JSON и показывает пример трассы протокола Contract Net. Требуется Python **3.10+**, сторонние библиотеки для основного моделирования не нужны.

По отдельности:

```bash
python mas_sim.py --lab 2 --trials 20
python mas_sim.py --lab 3 --trials 20
python mas_sim.py --lab 4 --trials 20
python -m unittest discover -s tests -v
```

Для пересборки графиков и отчетов после изменения алгоритма или параметров установите `matplotlib` и выполните:

```bash
python mas_sim.py --lab all --trials 20
python build_reports.py
```


### Условия моделирования

ЛР2: 4 агента, 48 задач в испытании, 20 seeds, 1-тактовая задержка решения CNP. Центральная схема использует **только статическую скорость без загрузки**; CNP учитывает очереди. Это полезная базовая сравнительная постановка, но не доказательство превосходства любого CNP над любым центром.

ЛР3: 4 агента, 1 GPU, спрос 37 слотов за 30 слотов горизонта. Независимые попытки могут конфликтовать; при торге брокер гарантирует не более одного выданного разрешения на слот. Сообщения не расходуют реальный слот времени, но учитываются в условных затратах.

ЛР4: 4 агента, 28 задач, 55 тактов, 20 seeds и 4 сценария: потеря назначений, отказ агента, недостоверная отрицательная ставка, поддельный отчет. «Проверка отправителя» здесь логическая; криптографических подписей нет.
